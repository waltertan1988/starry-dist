# starry-dist

这是一个采用JDK21、SpringBoot3.5、Spring Security、Docker Compose、Vue3、Element-Plus，含OAuth2单点登录认证的授权服务、可配置菜单和RBAC权限管理、可调用大模型（LLM）、前后端分离部署的后台管理平台，具体说明可参看：
* [后端部署说明](https://github.com/waltertan1988/starry-dist/tree/main/backend/starry-server#readme)
* [前端部署说明](https://github.com/waltertan1988/starry-dist/tree/main/frontend/starry-sso-vue3#readme)
* 下载：[界面操作说明](https://github.com/waltertan1988/starry-dist/tree/main/doc/Starry系统使用说明.docx)
